# KeyNest UI 概览设计规范

日期：2026-09-12  
状态：已确认，待实现计划

## 1. 目标

分别创建可独立运行的 Vue Web 与 Flutter Mobile UI 概览项目，用于确认 KeyNest 的完整界面方向。两端采用同一设计系统，但分别遵循桌面端和移动端的交互习惯。

本轮仅实现高保真界面与必要演示交互，不接入后端、数据库、真实认证、加密或同步。所有数据使用本地简体中文示例数据。

## 2. 视觉方向

采用已确认的「静谧系统感」：纯白与浅灰构成主要空间，通过留白、细边框和排版建立层级。界面不依赖大面积品牌色、厚重阴影、渐变、玻璃拟态或深色侧栏。

临时 Logo 使用圆角保险库轮廓与蓝色钥匙孔。图标统一为 1.5–2px 的圆润线性图标。

## 3. 设计系统

- 背景：`#FFFFFF`；次级背景：`#F7F8FA`、`#F8F9FA`。
- 文字：主要 `#1D1D1F`；次级 `#6B7280`；弱提示 `#9CA3AF`。
- 边框：`#E5E7EB`。
- 品牌色：`#4F7DF3`，仅用于主操作、选中、焦点、开关和少量状态强调。
- 状态色：危险 `#EF4444`、成功 `#22C55E`、警告 `#F59E0B`。
- 圆角：小控件 8px，输入框和按钮 10–12px，容器 14px，弹窗 18px，移动端 Bottom Sheet 顶部 24px。
- 阴影：默认不用；确需悬浮层级时使用 `0 1px 3px rgba(0,0,0,0.04)`。
- 字体：系统无衬线中文字体；API Key、Token、URL 等技术值使用系统等宽字体。
- 可点击区域最小 44px；焦点、按压、禁用状态均需有非颜色信息。

## 4. Vue Web 概览项目

技术栈为 Vue 3、TypeScript、Vite 与 Vue Router。提供顶部页面预览器，可访问：

1. 登录
2. 解锁密码库
3. 密码库三栏主界面
4. 登录账号详情
5. API Key 详情
6. 新建项目
7. 密码生成器
8. 设置
9. 设备管理

桌面密码库使用浅色 Sidebar、条目列表和详情区三栏布局。主内容限制在约 1100–1200px；平板切换为 Sidebar + Main，小屏切换为单栏。认证页面使用居中无卡片布局，设置和生成器使用聚焦的最大宽度内容区。

## 5. Flutter Mobile 概览项目

技术栈为 Dart、Material 3 与 GoRouter，以 390px 为主要设计宽度，并验证 360px、390px 和 430px。概览入口可访问：

1. 登录
2. 创建密码库
3. 恢复密钥
4. 解锁密码库
5. 首页
6. 密码库
7. 登录账号详情
8. API Key 详情
9. 新建项目
10. 密码生成器
11. 搜索
12. 设置
13. 设备管理

移动端采用单栏页面与固定四项底部导航：主页、密码库、生成器、设置。新建操作使用 Bottom Sheet，主要操作位于易于单手触达的区域。列表高度为 56–72px。

## 6. 组件边界

两端分别实现相同语义的基础组件：Logo、按钮、输入框、搜索框、Tag、Switch、列表项、敏感字段、状态提示、Toast、Dialog、Bottom Sheet 与 Empty State。

Vue 组件按基础控件、导航、条目展示、敏感内容和反馈分组；Flutter 使用 Theme Extension 管理令牌，并建立对应 Widget。示例数据集中维护，页面不重复定义同一项目内容。

概览入口只控制页面与视口切换；产品页面不显示“设计稿”或“演示”等辅助文案。

## 7. 演示交互与状态

- 支持页面切换、搜索、类型筛选、开关、弹窗和 Bottom Sheet。
- 密码、API Key 和 Token 默认遮盖；离开详情时恢复隐藏。
- 复制仅触发短暂“已复制”Toast，不写入真实敏感数据。
- 表单展示正常、空值、弱密码与格式错误状态。
- 删除条目、撤销设备等危险操作必须经过确认。
- 同步状态覆盖已同步、正在同步、离线和同步冲突，保持轻量呈现。
- 示例错误和反馈文案全部使用简体中文。

## 8. 数据流与安全边界

页面从只读的本地示例数据源取得条目与设备数据，交互状态保留在内存。预览器导航不把敏感值写入 URL、页面标题或持久化存储。页面切换事件统一触发敏感字段隐藏。

本轮 UI 不宣称实现真实加密、身份验证、生物识别或同步。相关操作明确作为视觉和交互演示，后续接入正式业务状态时复用组件语义而非示例数据实现。

## 9. 无障碍与响应式

- 正文和操作文字满足清晰对比度。
- Web 支持键盘导航和可见焦点，控件具备语义标签。
- Mobile 触控区域不小于 44px，避免底部安全区域遮挡。
- 内容放大后不截断重要操作；长名称、URL 和密钥可安全换行或省略。
- 状态不只依赖颜色表达，同时使用图标与文字。

## 10. 验证与完成标准

- Vue 项目通过类型检查和生产构建。
- Flutter 项目通过静态分析和关键 Widget 测试。
- 两端独立启动，所有优先页面均可从概览入口访问。
- 分别进行截图检查，修复溢出、截断、对比度和层级问题。
- 产品 UI 文案全部为简体中文；GitHub、OpenAI、API Key、Token、URL、SSH 等允许作为用户数据或技术名词出现。
- 两端视觉统一，但 Web 使用桌面信息密度与 Master/Detail，Mobile 使用底部导航、单栏页面和 Bottom Sheet，不进行简单缩放。
